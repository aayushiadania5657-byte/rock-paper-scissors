# Rock Paper Scissors

A command-line Rock Paper Scissors game built with Python while learning programming fundamentals, loops, functions, input validations, and basic game logic.

## Features

-Play Rock Paper Scissors against the computer
-Computer makes a random choice
-Three-round gameplay
-Score tracking
-Input validation
-Winner detection
-Functions used to organize the game logic

## Concepts Practiced

-Variables
-User input
-Conditional statements
-Loops
-Functions
-Parameters and return values
-Random module
-Tuples
-Input validation
-Basic problem solving

## How to Run 

Make sure Python is installed on your computer.

Run the following command in the project folder:

```bash
python rock-paper-scissors.py
